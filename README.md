# arancastro.github.io

Website for the **Daybloom** app and Dr Aran Castro's portfolio. The app itself lives in
[AranCastro/daybloom](https://github.com/AranCastro/daybloom).

| Path | Contents |
|---|---|
| `/` (`index.html`) | Home page for the **Daybloom** mobile app |
| `/app/` | Live web demo of the app (a copy of its web build, see the Daybloom README); also embedded in a phone frame on the home page |
| `/join/` | Page a buddy opens from the invite link (ntfy set-up and "I'm in" confirmation) |
| `/privacy/` | Privacy policy (used for the Google Play listing) |
| `/portfolio/` | Dr Aran Castro's academic portfolio (previously the site's home page) |

Android downloads: https://github.com/AranCastro/daybloom/releases/latest (builds up to 1.3.3 are in this
repository's releases).
